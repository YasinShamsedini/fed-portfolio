# Financial & Economic Data Portfolio

A collection of projects exploring **finance, economics, business, and data analysis** through statistical, quantitative, and computational methods. This repo documents my ongoing work with real-world datasets, analytical methods, and data-driven approaches to practical questions in finance and economics.
<br>

## Projects

* **[Economic Complexity Prediction](./eci_global_forecasting)** — This project aims to forecast countries’ Economic Complexity Index (ECI) through 2050 while exploring and visualizing key patterns, trends, and insights in global ECI data.

> More projects will be added as the portfolio develops.
<br>

* Python — Pandas, NumPy, Scikit-learn, SciPy

* Data Visualization
* Machine Learning
* Jupyter Notebook
* Git & GitHub


## Notes

* Projects are added and updated progressively as the portfolio develops.
